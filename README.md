# 老少平安 網站

## 網站說明

這是「老少平安社會企業有限公司」的官方網站初版。

### 重點設計
- 優先突出 **社區合作 / 學校推廣 / 義診服務**
- 服務項目清晰列出，並強調「歡迎查詢」
- 全站使用 WhatsApp 作為主要聯絡方式
- 香港繁體中文
- 響應式設計（手機優先）
- 配合印章 Logo 的朱砂紅配色

### 需要你修改的地方
1. **WhatsApp 號碼**：目前是 `852XXXXXXXX` 佔位符  
   請用文字編輯器全域搜尋 `852XXXXXXXX` 並改成真實號碼。

2. **地址、電話、營業時間**（如有需要可再加到 Footer）

### 檔案結構
```
laoshapingan-website/
├── index.html          # 主頁面
├── css/style.css       # 樣式
├── js/main.js          # 簡單互動
└── images/             # 圖片（Logo + 生成圖）
```

### 如何預覽
直接用瀏覽器打開 `index.html` 即可。

如需上傳到網頁空間，把整個資料夾內容上傳即可。
